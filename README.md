# Speexx Answer Vault — คลังคำตอบ

เว็บไซต์ธีมเทาดำสำหรับค้นหาโจทย์และเฉลยจากโฟลเดอร์ `solve data`
ใช้งานได้ทันทีโดยไม่ต้องติดตั้งอะไร — ดับเบิลคลิก `index.html` ก็เปิดได้เลย

---

## เปิดเว็บยังไง

มี 2 วิธี เลือกอันไหนก็ได้

1. **ดับเบิลคลิก `index.html`** — เปิดด้วยเบราว์เซอร์ปกติ (Chrome / Edge / Firefox)
2. **ดับเบิลคลิก `start.bat`** — เปิด `index.html` ให้อัตโนมัติ (สะดวกบน Windows)

> ไม่ต้องรันเซิร์ฟเวอร์ ไม่ต้องต่อเน็ต ข้อมูลและรูปถูกฝัง/เก็บไว้ในเครื่องแล้ว
> ถ้าเปิดแล้วหน้าจอว่าง ให้กด `Ctrl + F5` เพื่อรีเฟรชแบบล้างแคช

## ใส่รูปและข้อมูลของคุณ (Credit popup)

แก้ไฟล์ **`config.js`** ที่เดียว

```js
window.SITE_CONFIG = {
  owner: {
    name: "ชื่อของคุณ",              // ← ชื่อที่จะแสดงในป๊อปอัป
    handle: "@yourhandle",           // ← ชื่อ-user
    tagline: "ข้อความสั้น ๆ เกี่ยวกับคุณ",
    photo: "assets/profile.jpg",     // ← รูปของคุณ
    fallbackPhoto: "assets/profile.svg",
  },

  credit: {
    showOnLoad: true,                // false = ไม่ต้องเด้งทุกครั้งที่เปิด
    kicker: "CRAFTED WITH CARE",
    title: "ขอบคุณที่แวะมา",
    note: "ข้อความเครดิต/คำอธิบาย",
  },

  socials: [
    {
      label: "Facebook",
      handle: "facebook.com/yourprofile",
      url: "https://www.facebook.com/yourprofile",   // ← ลิงก์จริง
      icon: "facebook",
    },
    {
      label: "Instagram",
      handle: "@yourhandle",
      url: "https://www.instagram.com/yourhandle",   // ← ลิงก์จริง
      icon: "instagram",
    },
  ],
};
```

### เปลี่ยนรูปโปรไฟล์

1. เตรียมรูปสี่เหลี่ยมจัตุรัส (แนะนำ 400×400 px ขึ้นไป)
2. ตั้งชื่อไฟล์ว่า **`profile.jpg`**
3. วางทับไฟล์เดิมที่ **`assets/profile.jpg`**
4. เปิดเว็บใหม่ — รูปจะขึ้นในป๊อปอัปทันที

> ถ้าไฟล์รูปหายหรือโหลดไม่ได้ ระบบจะใช้ `assets/profile.svg` (รูปสำรอง) แทนให้อัตโนมัติ

### ไอคอนโซเชียลที่รองรับ

`facebook` · `instagram` · `github` · `youtube` · `discord` · `globe`
(ใช้ `globe` เป็นค่าเริ่มต้นถ้าใส่ชื่อไอคอนที่ไม่รู้จัก)

## การค้นหา (สไตล์ VSCode)

พิมพ์บางส่วนของ **โจทย์**, **หัวข้อ**, **คำตอบ** หรือ **ชื่อบทเรียน** ก็เจอ
ค้นหาหลายคำพร้อมกันได้ เช่น `market past tense` (ต้องมีครบทุกคำ)

ปุ่มตัวเลือกในช่องค้นหา เหมือน VSCode:

| ปุ่ม | ความหมาย |
|------|-----------|
| `Aa` | ตรงตามตัวพิมพ์เล็ก/ใหญ่ (case sensitive) |
| `ab` | ค้นหาทั้งคำเท่านั้น (whole word) |
| `.*` | ค้นด้วย Regular Expression |

**คีย์ลัด**

| ปุ่ม | การทำงาน |
|------|-----------|
| `Ctrl / Cmd + K` | โฟกัสช่องค้นหา |
| `Ctrl / Cmd + Shift + F` | โฟกัสช่องค้นหา |
| `Enter` | ค้นหาทันที |
| `Esc` | ล้างคำค้นหา / ปิดป๊อปอัป |

**ตัวกรอง**: เลือกระดับ A1 → Excellence, ประเภทคำตอบ, หรือเฉพาะข้อที่มีรูปภาพ
**ปุ่มอื่น ๆ**: สุ่มคำตอบ, คัดลอกโจทย์+เฉลย, คัดลอกลิงก์ตรงไปยังข้อนั้น, แชร์ลิงก์ผ่าน hash (`index.html#A1-0-0`)

## โครงสร้างไฟล์

```
Speexx Solve/
├─ index.html            ← หน้าเว็บหลัก (เปิดไฟล์นี้)
├─ styles.css            ← ธีมเทาดำทั้งหมด
├─ app.js                ← การค้นหา / ตัวกรอง / การแสดงผลเฉลย
├─ config.js             ← ชื่อ รูป และโซเชียลของคุณ (แก้ที่นี่)
├─ data.js               ← ฐานข้อมูลที่สร้างอัตโนมัติ (ห้ามแก้มือ)
├─ start.bat             ← ดับเบิลคลิกเพื่อเปิดเว็บ
├─ assets/
│  ├─ profile.jpg        ← ใส่รูปของคุณทับไฟล์นี้
│  ├─ profile.svg        ← รูปสำรอง
│  └─ images/            ← รูปประกอบคำตอบ 114 รูป
├─ scripts/
│  └─ build-data.mjs     ← ตัวสร้าง data.js จาก solve data
└─ solve data/           ← ไฟล์ JSON ต้นฉบับ 9 บท
```

## อัปเดตข้อมูลใหม่

ถ้ามีไฟล์ JSON ใหม่หรือแก้ไฟล์ใน `solve data/` แล้ว ให้รันคำสั่งนี้ในโฟลเดอร์หลัก:

```powershell
node scripts/build-data.mjs
```

สคริปต์จะ:

- รวมทุกไฟล์ `answers_*.json` เป็น `data.js`
- แปลงข้อมูลให้อยู่ในรูปแบบเดียวกัน (คำถาม, เฉลย, รูปภาพ)
- ดาวน์โหลดรูปภาพใหม่ที่ยังไม่มีลง `assets/images/` (รูปเดิมจะไม่โหลดซ้ำ)

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป (สำหรับ `fetch`)

## ข้อจำกัดของข้อมูล

ข้อมูลเหล่านี้มาจากไฟล์ต้นฉบับ จึงมีข้อจำกัดที่เว็บไม่สามารถแก้ได้:

- **โจทย์บางข้อถูกตัดกลางประโยค** — ไฟล์ต้นฉบับเก็บโจทย์ไว้ประมาณ 250 ตัวอักษรในบางบท
- **บางหน้าไม่มีเฉลยบันทึกไว้** — เว็บจะแสดงหมายเหตุ “ข้อนี้ไม่มีข้อมูลเฉลยในไฟล์”
- **ข้อเรียงประโยค (scrambled)** — ลำดับที่แสดงคือลำดับตามข้อมูลที่บันทึกไว้ อาจเป็นลำดับของ tile ที่ถูกสลับแล้ว ไม่ใช่ประโยคที่เรียงถูกต้องเสมอไป
- **ข้อที่มีรูปภาพ** — จับคู่รูปกับคำศัพท์ตามหมายเลข index จากข้อมูลต้นฉบับ
- **ตัวเลขในข้อเลือกตอบ** — เป็นดัชนีตัวเลือกเริ่มที่ 0 ตามลำดับตัวเลือกในโจทย์

เว็บนี้จัดทำเพื่อการทบทวนและฝึกภาษาเท่านั้น
