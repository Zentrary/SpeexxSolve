# Speexx Solve

คลังค้นหาโจทย์และเฉลยสำหรับทบทวนภาษาอังกฤษ มีหน้าแนะนำ การกรองระดับและประเภท แสดงผลตามลำดับบทเรียน และปุ่มคัดลอกคำตอบ ใช้งานฟรี เว็บไซต์นี้ไม่ใช่เว็บไซต์ทางการของ Speexx

## เริ่มใช้งาน

ติดตั้ง Node.js 18 ขึ้นไป แล้วรัน `npm start` จากโฟลเดอร์โครงการ เปิด `http://localhost:3000` ไม่สามารถเปิด HTML โดยตรงได้ เพราะการค้นหาทำงานบนเซิร์ฟเวอร์ รันการทดสอบด้วย `npm test`

## โครงสร้าง

- `public/` ไฟล์หน้าเว็บ ฟอนต์ Prompt และรูปที่เปิดสาธารณะ
- `public/js/config.js` แก้ชื่อ รูป และลิงก์เครดิต
- `api/search.js` API ค้นหา แสดงผลครั้งละ 20 รายการตามลำดับข้อมูลต้นฉบับ
- `server/data.json` ข้อมูลที่ API ใช้ ไม่ได้เปิดเป็นไฟล์สาธารณะในการตั้งค่า Vercel
- `server/dev.js` เซิร์ฟเวอร์สำหรับทดสอบในเครื่อง (ให้บริการเฉพาะ `public/` และ API)
- `solve data/` ไฟล์ JSON ต้นฉบับ
- `scripts/build-data.mjs` สร้าง `server/data.json` จากข้อมูลต้นฉบับด้วย `node scripts/build-data.mjs`
- `vercel.json` กำหนด route สำหรับ static files และ serverless API

## ความเป็นส่วนตัวของข้อมูล

การค้นหาฝั่งเซิร์ฟเวอร์ช่วยไม่ส่งไฟล์ข้อมูลทั้งหมดไปยังเบราว์เซอร์ และไม่เปิดเส้นทางตรงไปยังไฟล์ต้นฉบับบน deployment นี้ แต่ผลลัพธ์ที่แสดงต่อผู้ใช้ยังสามารถตรวจสอบและรวบรวมผ่าน API ได้ การปิด F12 ไม่ใช่มาตรการรักษาความปลอดภัย หากต้องการจำกัดการดึงข้อมูลจริงควรใช้บัญชีผู้ใช้ การจำกัดอัตราที่ระดับ shared infrastructure/WAF และเก็บข้อมูลในฐานข้อมูลส่วนตัว โดยไม่ใส่ข้อมูลลับใน repository สาธารณะ **repository นี้เป็นสาธารณะและมีข้อมูลต้นฉบับใน Git history อยู่แล้ว** การย้ายไฟล์ในเว็บไม่ได้ลบสำเนาที่เผยแพร่ไปก่อนหน้า ควรพิจารณาตั้ง repository เป็น private และจัดการประวัติ/สำเนาอย่างเหมาะสม

## Vercel

เชื่อม repository กับ Vercel และ deploy จาก branch ที่ต้องการ ตัวตั้งค่า `vercel.json` จะให้บริการเฉพาะไฟล์ใน `public/` และ API ใน `api/` ทดสอบว่า `/server/data.json`, `/solve%20data/answers_A1.json` และ `/data.js` ตอบ 404 หลัง deploy และตรวจสอบว่าการค้นหาและคัดลอกบน HTTPS ทำงานจริง อย่าตั้ง output directory เป็น repository root หรือเผยแพร่ `server/` และ `solve data/` เป็น static files
